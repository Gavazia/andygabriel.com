# andygabriel.com

Personal website for Andy Gabriel.

## Direction

A light, organic personal brand built around three pillars:

- Movement
- Content
- Technology

Visual system: warm white / soft grey, wine red, turquoise and restrained gold accents.

## Stack

Pure HTML, CSS and JavaScript. No build step required.

## Local preview

Open `index.html` directly or run any static HTTP server.

## Deployment

Designed to work with GitHub Pages and the custom domain `andygabriel.com`.
